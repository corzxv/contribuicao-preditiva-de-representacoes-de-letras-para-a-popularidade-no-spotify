# Contribuição preditiva de representações de letras para a popularidade no Spotify

TCC de **Felipe Macedo Cordeiro** em Estatística na Universidade de Brasília, sob orientação de **Leandro Tavares Correia**.

O trabalho compara modelos de classificação da popularidade musical para avaliar a contribuição das letras, além dos atributos acústicos e dos metadados do Spotify.

- [Monografia em PDF](output/pdf/monografia_template_overleaf.pdf)
- [Projeto editável para Overleaf](reports/monografia_template_overleaf.zip)
- [Resultados da classificação](reports/classificacao_9526_v1/interpretacao_resultados.md)
